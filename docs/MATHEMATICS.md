# Mathematics / математические основы

Документ описывает математические основы симметричного INT8-квантования, локального выбора кандидатов и глобальной оптимизации. Используемые конструкции известны в численной оптимизации; сравнение с опубликованными методами приведено в разделе литературы на уровне постановок задач, без прямого экспериментального сопоставления. См. [исходники исследовательского стенда](../research/benchmark_v4/algorithms/) и [результаты](../research/results/12_benchmark_v4_final/README.ru.md).

Связанные опубликованные методы и спецификации: [литература](REFERENCES.md).

## 1. Симметричное поканальное INT8-квантование

Для весовой матрицы $W\in\mathbb R^{d\times m}$, выходной канал $j$:

$$s_j=\max_i|W_{ij}|/127,\quad Q_{ij}=\mathrm{clip}(\mathrm{round}(W_{ij}/s_j),-127,127),\quad \widehat W=Q\mathrm{diag}(s).$$

Нулевые каналы требуют положительного безопасного масштаба. В реализации FP32 масштаб и фактическое декодирование учитываются явно. Объём хранения весов $dm+4m$ байт (без метаданных графа, нулевых точек и оставшихся FP32-тензоров). Для FP16-источника алгоритм поиска использует представление FP32, а экспорт добавляет Cast в FP16 после DQ; масштаб при необходимости ограничивается конечным диапазоном FP16 для фактических кодов. Локальный критерий при этом является приближением: итоговая проверка сравнивает выходы реального графа с исходной моделью. Для Conv нужно восстановить логический выходной канал, group layout и ось DQ; для Gemm учесть transB/alpha/beta и bias. Операторы, не прошедшие проверку семантики, исключаются из преобразования.

## 2. V1 Activation-aware integer descent

$X\in\mathbb R^{n\times d}$ — калибровочные активации, один канал $w$:

$$\min_{q\in[-127,127]^d\cap\mathbb Z^d,s>0} \|X(w-sq)\|_2^2,\qquad H=X^TX.$$

При фиксированном $s$ и невязке $r=X(w-sq)$ оптимальный вещественный шаг $q'=q+kh$ по целочисленному направлению $h$ равен:

$$k^*=\frac{(Xh)^Tr}{s\|Xh\|^2}.$$

Шаг $k$ округляется и ограничивается допустимым интервалом кодов. После проверки фактической ошибки обновляется невязка. Single: $h=e_i$. Paired: $h=e_i-\mathrm{sign}(x_i^Tx_j)e_j$, пары выбираются в блоках по $2|x_i^Tx_j|/(\|x_i\|^2+\|x_j\|^2)$. Масштаб для фиксированных кодов: $s^*=(Xq)^TXw/\|Xq\|^2$ с безопасной проверкой. Ошибка после FP32-деквантования сравнивается с MinMax в FP64; при ухудшении канал сохраняет вариант MinMax. Локальная монотонность не означает глобальную оптимальность и не гарантирует обобщения. Для больших слоёв полная плотная матрица Грама не формируется. При $T$ проходах сложность координатной части составляет примерно $O((T+1)ndm)$; блоковые пары добавляют затраты профилирования, бюджет ограничивает каналы.

## 3. V2 Output-aware selection

Для каждого слоя строится банк допустимых вариантов. Отклик замены на логиты измеряется относительно опорного выхода $Z_0$; аппроксимация $\widehat Z=Z_0+\sum_l D_{l,a_l}$. Лучевой поиск по MSE и опциональному margin loss относительно FP32. Нелинейность ограничивает аддитивную аппроксимацию; поэтому выбор проверяется реальным прямым проходом на dev с возвратом к базовому варианту при ухудшении. V2 требует одного тензора логитов классификации. V4 ограничивает число активных слоёв и использует отдельный точный жадный поиск для произвольных выходов. Выигрыш V2 зависит от модели и данных.

## 4. QK-SVD (отрицательный результат)

При фиксированном произведении $AB^T=U\Sigma V^T$ можно использовать $A'=U\sqrt\Sigma, B'=V\sqrt\Sigma$ (с упаковкой bias). Балансировка минимизирует определённую факторизационную нормовую оценку, но не обязательно фактическую INT8 ошибку. На BERT принудительная SVD ухудшила MSE, все четыре головы не прошли критерий принятия. Метод не включён в продуктовые режимы.

## 5. SDR — spectral dependent rounding

Масштаб MinMax фиксирован. Столбцы матрицы активаций $A$ нормированы, а отклонения $v$ масштабированы нормами исходных столбцов. Нижние/верхние допустимые уровни $l_i,u_i$ вычисляются из фактического FP32 DQ floor/ceil. Потенциал:

$$\Phi(v)=\|Av\|^2+\sum_i(v_i-l_i)(u_i-v_i).$$

Для активного блока $C=A_B^TA_B$ с единичной диагональю среднее собственное значение 1, поэтому $\lambda_{\min}\le1$. Кривизна потенциала вдоль минимального собственного вектора пропорциональна $\lambda_{\min}-1\le0$. Алгоритм выбирает одну из двух границ с меньшим потенциалом, фиксирует координату и завершается на вершине. Верхняя оценка относительно ожидания независимого случайного округления, **не гарантия выигрыша относительно MinMax**. Фактическая ошибка после FP32-деквантования проверяется с возвратом к MinMax по каналу. Размер блока ограничивает рабочую память и объём вычислений. Синтетические эксперименты показывают пользу при коррелированных активациях, но возможное ухудшение в недоопределённых задачах и при сдвиге распределения.

## 6. Robust Guard

Для ошибки матрицы $E_a=W-\widehat W_a$ и нормированного второго момента активаций $H$ средняя ошибка на выходной канал определяется как:

$$L_a(H)=\mathrm{tr}(E_a^THE_a)/m.$$

Здесь $H=X^TX/n$ для выборки. Для разницы с baseline $\Delta_{dev}=L_a(H_d)-L_0(H_d)$ и аналогично fit:

$$U_a=\Delta_{dev}+|\Delta_{dev}-\Delta_{fit}|+\rho(\|E_a\|_F^2+\|E_0\|_F^2)/m.$$

Для множества возмущений $H=H_d+t(H_d-H_f)+D$, $|t|\le1$, $\|D\|_2\le\rho$, верхняя граница следует из треугольного неравенства и $|\mathrm{tr}(E^TDE)|\le\|D\|_2\|E\|_F^2$. В коде `Loss` хранит агрегированную энергию на канал, так что деление уже учтено; повторное деление на число каналов не требуется. Радиус — эвристическая оценка по ошибке MinMax на fit/dev, а не доверительный интервал. Принимаются только варианты с отрицательной верхней оценкой; MinMax всегда доступен. Затем выполняется проверка выходов модели.

## 7. Progressive / Progressive-Global

После MinMax последовательно строятся Single, Paired и SDR. Поиск останавливается, когда робастная верхняя оценка выбранного варианта не превышает $-0.25 L_0(H_d)$ или исчерпан вычислительный бюджет. Используется лучший допустимый вариант либо MinMax. В исследовании v4 эти политики оценивались на заранее построенном банке; в приложении реализовано ленивое построение кандидатов в `quantlab/weight_only/`. Глобальный поиск работает только по допущенным построенным вариантам, максимум 4 активных слоя: V2 для одного выхода классификации и точный жадный поиск с лимитом 9 вызовов для произвольных выходов. На `global_search` кандидат принимается по неухудшению всех MSE и строгому выигрышу хотя бы одного. На отдельной выборке `global_check` локальная и глобальная конфигурации сравниваются с MinMax для всех слоёв; выбирается допустимая конфигурация с меньшим средним нормированным MSE. При отсутствии улучшения сохраняется MinMax. Тестовая выборка не участвует в выборе. При нулевом знаменателе относительная ошибка определяется как нулевая или бесконечная в зависимости от числителя. Метрики целевой задачи и ресурсные ограничения проверяются отдельно. Детерминизм и сохранение размера не равны доказательству ускорения.

## 8. Критерий v4 и интерпретация

Для каждой пары модель/seed вычисляется максимум по численным выходам MSE(candidate, FP32)/MSE(MinMax, FP32), затем медиана по seed; итог — среднее восьми модельных медиан. Критерии принятия: полнота эксперимента и равный размер моделей; каждая модель test <=1.02, shift <=1.05, accuracy delta >=-0.01, task RMSE <=1.02 (если измерены); >=2 модели test <=0.95. Дополнительно проверяются отдельные запуски, тогда как критерии принятия используют медианы. Нет гарантии будущих данных. FP32 fidelity не означает точность на размеченной задаче, особенно ImageNet logits на CIFAR-10. Нельзя сравнивать MSE разномасштабных выходов без нормировки. Сравнение с AdaRound, GPTQ, COMQ и другими опубликованными подходами остаётся направлением дальнейшей работы.
