# ONNX Quantization Lab v1.0.0-rc2 — Research Preview

Adaptive INT8 weight quantization for ONNX models with robust candidate selection and progressive optimization.

## Highlights

- Four modes: Standard (MinMax), Fast (Single-Robust), Balanced (Progressive), Quality (Progressive-Global).
- Supported constant FP32 weights in MatMul, Gemm and Conv; INT8 storage with FP32 dequantization.
- Robust candidate selection, lazy evaluation, bounded global search and MinMax fallback on held-out checks.
- Web interface for model inspection, quantization, inference and labeled dataset evaluation.
- JSON reports, Docker deployment, research code and mathematical documentation.

## Evidence

- Digits CNN smoke test (Standard): 70.77% smaller file, 98.66% accuracy before and after, identical predictions on 373 examples. Measured speed ratio: 0.86×.
- Historical v4 benchmark (8 models, 3 seeds): average of model medians of worst-output MSE ratio to MinMax was 0.6435 for Fast, 0.5444 for Balanced and 0.5011 for Quality. These are research replay results, not an independent product benchmark.

## Changes since rc1

- Public documentation, Apache-2.0 licensing, security guidance and reference list.
- GitHub Actions regression workflow and repository presentation assets.
- No changes to quantization algorithms.

## Getting started

With Docker and Docker Compose installed, run `docker compose up -d --build quantlab` from the repository root, then open http://127.0.0.1:7860. The first build requires Internet access for dependencies and demo assets. Model weights and datasets are not distributed in Git.

## Limitations

Research preview, CPU-only runtime, partial ONNX operator coverage, self-contained model files only. Weight-only compression does not guarantee faster inference or unchanged predictions. The work budget is not a hard time/memory limit. Do not treat the application as a complete sandbox for untrusted models. Direct comparisons with published quantization methods have not been performed.
