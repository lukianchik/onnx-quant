# ONNX Quantization Lab v1.0.0-rc3

## Changes

- FP16 weight quantization in all four modes.
- Mixed-precision FP32/FP16 support.
- Preservation of original weight types.
- FP16 calibration and numerical stability checks.
- Updated parameter coverage metrics.
- Synthetic FP16 demonstration model.

## Validation

- 84 regression tests passed.
- Standard, Fast, Balanced and Quality modes.
- MatMul, Gemm and Conv operators.
- ONNX export and ONNX Runtime inference.
- Dataset evaluation and interface tests.

## Limitations

- CPU-only execution.
- Partial ONNX operator coverage.
- Weight compression does not guarantee faster inference.
